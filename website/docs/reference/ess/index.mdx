# ESS specification

thalamus is specified in ESS before it is implemented. This page and the domain pages below are generated from the repository's `spec/` directory by `thalamus-docs`: the graphs from `ess specify compile`, the pages from `ess generate --kind docs`. They change when the specification changes, and `task check` fails if they fall behind it.

The Rust model (`generated/thalamus-model`) and the serde types of every record (`generated/spec-types`) are generated from the same files. The [contract explorer](./explorer.mdx) shows the whole specification in one searchable view.

## Assertions

A caller (a release, a merge request, a test run, a controller) asks whether named signals stayed within baseline over a window, and thalamus answers with a result, not a guess. Unknown is not a pass.

## Signal definitions

## Dimensions

The closed, per-instance set of dimension keys a sample may carry, and where each key's values resolve.

## Evaluations

One verdict over one sample, with the rule and the definition revision that decided it. Kept apart from the sample so a threshold change re-grades history without reading the source again.

<DomainGraph data={domainGraph3} title="Evaluations" />

[Read the Evaluations domain in full](./thalamus-evaluation.md)

## Samples

One reading of one signal for one series. Append-only; a sample has no lifecycle beyond being recorded.

<DomainGraph data={domainGraph4} title="Samples" />

[Read the Samples domain in full](./thalamus-observation.md)

## Daily rollups

One row per series per UTC day, kept after the raw samples leave retention. It is what a source that cannot be re-queried (history store) leaves behind.

<DomainGraph data={domainGraph5} title="Daily rollups" />

[Read the Daily rollups domain in full](./thalamus-rollup.md)

## Transitions

A settled change of a series' verdict, emitted by the hysteresis once k consecutive evaluations agree. It copies what a reader needs from the evaluations that settled it, so it outlives their raw retention.

<DomainGraph data={domainGraph6} title="Transitions" />

[Read the Transitions domain in full](./thalamus-transition.md)
