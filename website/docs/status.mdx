**Shipped** means code on `main` today, held by a test or by a step of `task check`. **Planned**
means an item in the repository's planning store (`.engineering/`) and nothing more; each planned
item names it.

<StatusTable data={status} />

The list is generated by `thalamus-docs` from `crates/thalamus-docs/src/status.rs`. Generation
fails when a shipped item's test or task does not exist, or when a planned item's planning artifact
does not, so a claim here cannot outlive what it rests on.

The [ESS reference](/docs/reference/ess) is generated from the specification, which is the part
of thalamus that exists today.
