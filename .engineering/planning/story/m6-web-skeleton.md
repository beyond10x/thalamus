## Context

`epic:web-ui` Ships: "A `web/` Vue 3 + TypeScript app, built at development time; the built files are committed and served by `thalamus-service` under one route prefix, so running the service needs no Node", and the type check and unit tests of its own checks. The decisions are `story:m6-design-record` items 1, 2 and 6. Precedent: `~/beyond10x/uilab` keeps its app in `widget/` and serves it as built files from Rust; unlike uilab, which ignores `widget/dist` and serves it from an `--assets` directory, the built files here are committed and embedded, because the epic asks that running the service need no Node.

Like `story:m4-skeleton` and `story:m5-skeleton`, this story is the prefactoring the other M6 stories depend on. It lays every shared line once (the route table, the module lines, the npm manifest, the app shell and its three routes), so `story:m6-signal-board`, `story:m6-series-view` and `story:m6-flow-view` each fill their own files and can share a wave. The one output they all rewrite is `web/dist/`, which the coordinator rebuilds at merge with `task web-build`, as it regenerates `Cargo.lock`.

It lands after `story:m5-skeleton`, the last story that edits `crates/thalamus-service/src/http.rs` and `crates/thalamus-service/src/lib.rs`, and after `story:m4-skeleton`, the last that edits `crates/thalamus-service/Cargo.toml`. Its route tests use the in-process technique of `story:m4-skeleton` (`http::router`, `tower::ServiceExt::oneshot`, no socket).

## Work

- `web/` (new):
  - `package.json`: `vue`; dev dependencies `vite`, `@vitejs/plugin-vue`, `typescript`, `vue-tsc`, `@types/node` and the JSON Schema validator `story:m6-web-types` uses; `engines.node` pinned to the major CI runs; scripts `typecheck`, `test` (`node --test` over `src/**/*.test.ts`) and `build`. Every npm dependency of M6 is declared here once; no later story edits `package.json` or `package-lock.json`.
  - `package-lock.json`, `tsconfig.json`, `vite.config.ts` (base `/ui/`), `index.html`, `src/main.ts`.
  - `src/App.vue`: the shell, a header linking the three views and one `<main>`; it fetches nothing.
  - `src/lib/route.ts` and `src/lib/route.test.ts`: the hash router; `#/` the board, `#/series/<key>` with the D10 series key URL-encoded, `#/flow`; an unknown hash shows the board.
  - view stubs `src/views/Board.vue` (`story:m6-signal-board`), `src/views/Series.vue` (`story:m6-series-view`) and `src/views/Flow.vue` (`story:m6-flow-view`), each rendering `not implemented` and filled by exactly one story.
- `web/dist/` (new, committed): the build of the above.
- `crates/thalamus-service/Cargo.toml` (owned by `story:m2-scheduler`, after `story:m4-skeleton`): `include_dir` under `[dependencies]`, and the feature `web-e2e` with no dependency, which `story:m6-web-e2e` uses; nothing else. `Cargo.lock` is regenerated by the coordinator at merge.
- `crates/thalamus-service/src/lib.rs`: module lines `web`, `api_transitions`, `flow`.
- `crates/thalamus-service/src/web.rs` (complete here): the embedded `web/dist`; `GET /ui` answers 308 to `/ui/`; `GET /ui/` answers `index.html`; `GET /ui/{*path}` answers the file with its content type from its extension (`html`, `js`, `css`, `svg`, `json`, `woff2`, otherwise `application/octet-stream`) or 404; every `/ui/` answer carries `Content-Security-Policy: default-src 'self'` and `X-Content-Type-Options: nosniff`.
- Stubs answering 501 `not implemented`: `crates/thalamus-service/src/api_transitions.rs` (`story:m6-series-view`) and `crates/thalamus-service/src/flow.rs` (`story:m6-flow-view`).
- `crates/thalamus-service/src/http.rs` (owned by `story:m4-skeleton`, after `story:m5-skeleton`): route lines `GET /ui`, `GET /ui/`, `GET /ui/{*path}`, `GET /api/transitions` and `GET /api/flow/stream`; the index at `/` links `/ui/`. Other methods answer 405, as on every route.
- `crates/thalamus-service/tests/web.rs` (new).
- `Taskfile.yml`: `web-build` (rebuild `web/dist/`) and `web-check` (design item 2), `check` calling `web-check` after `drift`.
- `.github/workflows/check.yml`: Node set up by `actions/setup-node`, pinned by commit SHA, at the version `web/package.json` pins.
- `.gitignore`: `/web/node_modules/`.
- `AGENTS.md`: the `web/` row of the layout table, `task web-build` and `task web-check` in the command table, and the hard rule "Committed code is Rust" amended with the `web/` exception, citing its design § 11 row.

## Decisions taken here (decomposer calls, reversible)

- npm, not pnpm as uilab uses: `website/` already builds with npm, so the repository keeps one Node package manager.
- One web skeleton for M6, as `story:m4-skeleton` and `story:m5-skeleton` did for theirs, so the three view stories touch no shared file except `web/dist/`.
- The route tests assert what stays true after the stubs are filled (405 on a write), not the 501, so `story:m6-series-view` and `story:m6-flow-view` never edit `tests/web.rs`.
